# Caso 01 — monopatines — input para skill-generar-escenarios-calidad

> Fragmento crudo del enunciado original de TP3 (sistema de alquiler de monopatines eléctricos), sin resolver, tal como se cita en la resolución de Notion del ejercicio 3-A. La skill debe procesarlo desde cero y producir un escenario de atributo de calidad con el template de 6 partes.

## Requerimiento a procesar

"Cada usuario debe crearse una cuenta asociada a una cuenta de Mercado Pago, que le permitirá cargar crédito a la cuenta del servicio. Una cuenta de Mercado Pago puede estar vinculada a varias cuentas de usuarios del servicio."

## Consigna para la skill

A partir de este fragmento, identificar el atributo de calidad relevante (más allá de la funcionalidad de alta de cuenta en sí) y generar el escenario correspondiente con las 6 partes del template SEI.
