| Atributo de Calidad | Refinamiento | ASR (Resumen) | Prioridad (Valor, Riesgo) |
| :--- | :--- | :--- | :--- |
| Performance | Peak load | Varios servidores de tiempo envían traps al sistema de gestión en el pico de carga; el 100% de los traps se procesan y almacenan con éxito. | (M, H) |
| Modificabilidad | Protocol update | Se introduce un nuevo protocolo de gestión como parte de una actualización. Se agrega sin cambios en los componentes core del sistema. | (H, L) |
| Disponibilidad | SW failure | Ocurre una falla en el sistema de gestión durante la operación normal y reanuda su operación en menos de 30 segundos. | (H, H) |
| Usabilidad | Learnability | Un usuario nuevo puede configurar su cuenta y estar operando con menos de 8 horas de entrenamiento. | (L, L) |
